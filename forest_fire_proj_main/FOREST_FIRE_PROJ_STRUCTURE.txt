------------------------------------------------------------------------

PROJECT FLOW:

1.  Download MODIS CSV → place inside data/raw/
2.  Run preprocess_modis.py → creates data/processed/modis_processed.csv
3.  Download VIIRS (later) → preprocess similarly
4.  Merge datasets → create final_dataset.csv
5.  Train ML model → save inside models/
6.  Evaluate and visualize results

------------------------------------------------------------------------

This structure keeps: - Raw data separate from processed data - Source
code clean and modular - Models saved separately - Future expansion
possible (CNN, LSTM, etc.)
